What the student must do

Start from singletons. Repeatedly contract the highest-affinity legal pair into a supernode. Stop at target K, or when no legal positive-weight pair remains. Report the partition and its cutsize.

There is no undo. Heavy nets should disappear from the cut; weak bridges may stay cut. Capacity (max cluster size) is optional, but when it is on it can block the unconstrained path.

Walkthrough — every node starts alone

Use the step buttons. Contracting affinity w drops cutsize by exactly w.

Why step 2 is AB–C, not D–E: both pairs have affinity 5. Labels AB/C vs D/E; AB < D, so AB–C wins. Final cut = C–D (2) + C–E (1) = 3. Golden: ABC|DE.

Capacity = 2 forks the path

Same graph, same K=2, but a cluster may hold at most two cells. Size-3 {A,B,C} is illegal, so after A–B the 5-edge D–E fires. Then C has no legal partner and the run stops at three clusters.

Implement track

This is Track A: write the code yourself. The commands below are only the reference check. You can also run the same goldens with buttons (they switch to the Lab tool).

1. What “done” looks like

Run the reference solver down to two clusters. You should land on A–B–C versus D–E with cutsize three.

parts=ABC|DE cutsize=3

Keep a deterministic lexicographic tie-break so golden tests stay reproducible. Do not invent a merge to force K when capacity strands the run.

2. What you re-implement

  1. Cluster affinity = sum of crossing edge weights (parallels add).
  2. Capacity filter = skip a pair if |A|+|B| exceeds the cap, before ranking.
  3. Tie-break = lexicographic cluster labels (sorted member names joined).
  4. Contraction + a cutsize log after every merge.

3. Check the reference (from the folder that contains examples/)

Confirm you are in the right tree, then run the three goldens.

Pitfalls to watch

  • Greedy is myopic: a great first merge can strand you with a bad global cut. Later labs repair seeds with refinement (FM / KL), not by undoing greedy.
  • Watch illegal merges that violate a size cap — test capacity before ranking, not after.
  • Updating affinities incorrectly after contraction creates silent wrong clusters until goldens fail.
  • A missing lexicographic tie-break makes AB–C versus D–E a coin flip, so tiny_graph tests flake.
  • Capacity can leave isolated cells. Report actual |parts| and cutsize.
